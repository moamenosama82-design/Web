# Arabic Exam System

A web-based **Arabic Exam System** built with **PHP**, **MySQL**, **JavaScript**, **HTML**, **CSS**, and **Java** for managing interactive exams and tracking student results.

## Overview
This project provides an online examination platform for Arabic exams, supporting user access, dynamic question loading, interactive exam flow, and result storage.

## Key Features
- **Exam & Quiz Flow:** Interactive exam interface with dynamic question handling and result saving.
- **Database Integration:** Stores questions, users, and exam scores in MySQL.
- **Responsive UI:** Built with structured HTML, CSS, and JavaScript for smooth user interaction.
- **Backend & Java Components:** Combines PHP/MySQL web handling with Java components.

## Technologies Used
- **Backend & Database:** PHP, MySQL, Java
- **Frontend:** HTML, CSS, JavaScript

## How to Run
```bash
git clone [https://github.com/moamenosama82-design/Web.git](https://github.com/moamenosama82-design/Web.git)
cd Web/arabic_exam

 * Start Apache and MySQL (e.g., via XAMPP) and place the project inside your web server root (htdocs).
 * Create a MySQL database and import the SQL schema/data.
 * Update the database connection settings in your config/API files if needed.
 * Open the project in your browser via http://localhost/Web/arabic_exam/.
